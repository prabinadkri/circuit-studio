Routing constraints & layer stack

Fixed 0.5 mm track width and 0.25 mm clearance. Every operation checks copper and rolls back if no legal result is found. Route indices start at 0; pad IDs use reference:number (for example J1:1).

Routes and length tuning

Differential pair

Aligned endpoints must match the gap. The circuit API also accepts a center path; mismatched lengths are refused. Geometry constraints do not calculate impedance.

Push / shove

Searches bounded orthogonal detours while keeping pads and vias fixed. Constrained pairs are fixed obstacles.

Blind / microvia

Microvias join an outer layer to its neighbor. Blind/buried drills require ≥0.2 mm; microvias ≥0.1 mm. A fabricator must validate the laminate and process.

Capture guide & limits

Click the plot to place cursors alternately. Voltages are sampled at the exchange interval; GPIO transitions retain backend instruction-completion timestamps. Capture retains 200,000 transitions and 20,000 frames from the first 64 labeled nodes. CSV includes both record types on the same 0.5 ns timebase. Digital Z (high impedance) and X (contention) appear at mid-level. GPIO uses a generic 30 Ω / 30 kΩ pull-up model. The firmware simulation pauses with a single capture; it is not a physical instrument.

Protocol & peripheral lab

Assign MCU pins

Pin instruments observe MCU output transitions. Wire LAB_SDA, LAB_SCL and LAB_MISO External Voltage returns to the assigned MCU nets; SDA/SCL need pull-ups. The example uses bit-banged firmware. Existing USART monitor still handles hardware UART bytes. EEPROM 0x50: 32 KiB, 64-byte pages, 5 ms write busy. OLED 0x3C: 128×64, horizontal/page addressing subset. SPI byte slave returns A5 first, then the previous received byte. LCD: write-only 4-bit interface, R/W tied low, 16×2 DDRAM view. These behavioral models do not model supply, contrast or device electrical damage.

Reusable circuits & assembly variants
Circuit blocks
Save the current schematic as a reusable snapshot. Place copies with isolated named nets and unique component/pin identities. Ground is shared. Map ports explicitly to parent net names to connect blocks. Nested snapshots preserve their hierarchy paths.
Place in empty canvas space. Copies are editable snapshots; changes to one do not update other instances. Supported basic analog/logic parts retain model settings. MCU, custom behavioral and upstream subcircuit models are rejected. Use named ports such as DATA0…DATA7 for buses.

Assembly variants
Update the PCB first. Uncheck a component to mark it DNP (do not populate); enter a procurement value for a variant. All variants retain the same PCB pads, routes and schematic simulation. The exported BOM carries stable source identities.
