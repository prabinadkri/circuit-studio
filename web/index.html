Connect firmware to your schematic

Use an External Voltage component named D0 through D13 to receive an output. Use a labeled node named IN_D0 through IN_D13 to supply an input.

The firmware and circuit use independent clocks; GPIO is sampled between execution batches. This is functional GPIO simulation, not timing-accurate mixed-signal co-simulation. Choose from the tested device profiles above. Select the matching target before loading firmware: Intel HEX does not identify its processor. Compile source to HEX using an external toolchain.

Choose a part from the left, then click the canvas to place it. You can also drag to set its size. Wires need a drag between connection points. W draws a wire; R draws a resistor. Use Select / move to reposition parts. Double-click to change a value.

Right-click a part → View in Scope for a waveform. The editor’s Draw and Circuits menus contain the full library and examples.

Save file downloads a Circuit Studio project (schematic, firmware and board). Open restores one. Autosave keeps the latest circuit in this browser profile; save a file for a portable backup.

AVR firmware and PCB layout share this project. PCB transfer currently supports two-pin components only. PIC16 and PIC18 firmware use the native PICsim backend. Proteus file import is not implemented.
